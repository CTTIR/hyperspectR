# hyperspectR: Hyperspectral Imaging Analysis for Biomedical Applications

Reads, processes, analyzes and visualizes hyperspectral imaging (HSI)
data from Cubert snapshot cameras, Diaspective Vision 'TIVITA'
recordings and standard 'ENVI' and 'TIFF' files. Provides calibration
workflows (dark correction, white reference normalization), spectral
preprocessing (Savitzky-Golay smoothing, standard normal variate (SNV),
multiplicative scatter correction (MSC), derivatives), dimensionless
spectral indices, research hemoglobin fraction fitting, dimensionality
reduction (principal component analysis (PCA), minimum noise fraction
(MNF)), pixel classification (spectral angle mapper (SAM), support
vector machines (SVM), random forest) and constrained spectral unmixing.
Includes an interactive 'shiny' explorer, reproducible batch recipes and
grouped evaluation tools. Results are research outputs; clinical or
device-specific accuracy is not established by the included synthetic
examples.
