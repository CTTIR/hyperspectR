# hyperspectR: Hyperspectral Imaging Analysis for Biomedical Applications

Read, process, analyze, and visualize hyperspectral imaging (HSI) data
from Cubert snapshot cameras and standard ENVI/TIFF formats. Provides
calibration workflows (dark correction, white reference normalization),
spectral preprocessing (Savitzky-Golay smoothing, SNV, MSC,
derivatives), dimensionless spectral indices, research hemoglobin
fraction fitting, dimensionality reduction (PCA, MNF), pixel
classification (SAM, SVM, random forest), and constrained spectral
unmixing. Includes an interactive 'shiny' explorer, reproducible batch
recipes and grouped evaluation tools. Results are research outputs;
clinical or device-specific accuracy is not established by the included
synthetic examples.
